# Impawct Hammer

Changes the Impact Hammer Gauge to a paw! Made it for personal use, but thought it looked cool enough to share.

## **How to use:**

1. Install this mod manually or with a mod manager. Install its dependencies, ULTRASKINS-GC and USGCColorOverride, if you do not have them already. r2modman does this automatically.
2. Click the "US" button on the main menu.
3. Find "Impawct Hammer" in the list and click it. (The box will be filled with an X if it's enabled). Click "Apply".

If the gauge is unaffected after enabling this pack, move it to the top of the list in the ULTRASKINS menu.

If Impawct Hammer does not appear in the list, click the plus button at the bottom of the list. Click "Add undetected ThunderStore skin", find this mod, and click it. If it doesn't appear in that list either, follow the steps below but copy the files from the folder for this mod instead.
